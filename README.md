# വിപണി സൂപ്പർമാർക്കറ്റ് - Full-Stack Shop Management & E-Commerce Web App

നിങ്ങളുടെ പുതിയ ഷോപ്പിനായി സാധനങ്ങൾ ലിസ്റ്റ് ചെയ്യാനും (Admin Product Management), ഉപഭോക്താക്കൾക്ക് ഓൺലൈനായി സാധനങ്ങൾ കാണാനും, ഓർഡർ ചെയ്യാനും, പണമടയ്ക്കാനും (Customer Storefront & Online Payment) സാധിക്കുന്ന സമ്പൂർണ്ണമായ സോഫ്റ്റ്‌വെയർ ആപ്ലിക്കേഷൻ.

---

## 🌟 പ്രധാന സവിശേഷതകൾ (Key Features)

### 1. അഡ്മിൻ / ഷോപ്പ് ഉടമസ്ഥൻ (Shop Owner & Admin Portal)
- **അഡ്മിൻ ലോഗിൻ**: സുരക്ഷിതമായ ലോഗിൻ സംവിധാനം (`admin@shop.local` / `admin123`).
- **ഉൽപ്പന്ന മാനേജ്‌മെന്റ് (Product CRUD)**:
  - പുതിയ ഉൽപ്പന്നങ്ങൾ ചേർക്കുക (Name in English & Malayalam, Category, Price, MRP, Stock, Unit, Icon/Image).
  - നിലവിലുള്ള ഉൽപ്പന്നങ്ങൾ എഡിറ്റ് ചെയ്യുക, ഒഴിവാക്കുക (Delete).
  - ഒരൊറ്റ ക്ലിക്കിൽ സ്റ്റോക്ക് കൂട്ടാനും കുറയ്ക്കാനുമുള്ള ക്വിക്ക് അഡ്ജസ്റ്റ്മെന്റ് (`+5` / `-1`).
- **തത്സമയ ഓർഡർ മാനേജ്‌മെന്റ് (Live Orders)**:
  - കസ്റ്റമേഴ്‌സ് നടത്തുന്ന എല്ലാ ഓർഡറുകളും തത്സമയം കാണാം.
  - ഓർഡർ സ്റ്റാറ്റസ് മാറ്റുക: **Pending → Processing → Shipped → Delivered**.
  - ഉപഭോക്താക്കളുടെ വിലാസവും ഫോൺ നമ്പറും കാണാം.
- **സെയിൽസ് അനലിറ്റിക്സ് & ഡാഷ്‌ബോർഡ്**:
  - ആകെ വരുമാനം (Total Revenue ₹)
  - ആകെ ഓർഡറുകൾ (Total Orders)
  - സ്റ്റോക്ക് കുറഞ്ഞ സാധനങ്ങളുടെ മുന്നറിയിപ്പ് (Low Stock Alerts)
- **ഷോപ്പ് വിവരങ്ങൾ ക്രമീകരിക്കൽ (Store Settings)**:
  - ഷോപ്പിന്റെ പേര്, വിലാസം, ഫോൺ നമ്പർ, UPI ID, സൗജന്യ ഡെലിവറി തുക എന്നിവ മാറ്റാം.

### 2. ഉപഭോക്താക്കൾ (Customer Storefront & Checkout)
- **ഉൽപ്പന്നങ്ങൾ കാണലും തിരയലും (Catalog & Search)**:
  - കാറ്റഗറി അടിസ്ഥാനത്തിൽ ഫിൽട്ടർ ചെയ്യാം (Groceries, Fresh Produce, Spices, Snacks, Dairy, Home Care).
  - തത്സമയ സെർച്ച് (Live Search) & വില അടിസ്ഥാനമാക്കിയുള്ള സോർട്ടിംഗ്.
  - സ്റ്റോക്കുള്ള സാധനങ്ങൾ മാത്രം കാണാനുള്ള ഫിൽട്ടർ.
- **ഷോപ്പിംഗ് കാർട്ട് (Cart Drawer)**:
  - ക്വാണ്ടിറ്റി കൂട്ടാനും കുറയ്ക്കാനുമുള്ള സൗകര്യം.
  - സൗജന്യ ഡെലിവറിക്ക് ഇനിയും എത്ര രൂപയുടെ സാധനം വേണമെന്ന് കാണിക്കുന്ന തത്സമയ മീറ്റർ.
- **ഓൺലൈൻ പേയ്‌മെന്റ് സിസ്റ്റം (Online Payment Integration)**:
  - **UPI (Google Pay, PhonePe, Paytm, BHIM, QR Code Scan)**
  - **Debit / Credit Card (Visa, RuPay, MasterCard)**
  - **Net Banking (All Indian Banks)**
  - **Cash on Delivery (COD)**
- **ഡിജിറ്റൽ ഇൻവോയ്സ് / പ്രിന്റബിൾ ബിൽ (Digital Tax Invoice)**:
  - ഓർഡർ പൂർത്തിയായയുടൻ പ്രിന്റ് ചെയ്യാനും ഡൗൺലോഡ് ചെയ്യാനും സാധിക്കുന്ന ജിഎസ്ടി/റീറ്റെയ്ൽ ബിൽ.
- **ഓർഡർ ട്രാക്കിംഗ് (Live Order Tracking)**:
  - ഫോൺ നമ്പറോ ഓർഡർ നമ്പറോ ഉപയോഗിച്ച് ഓർഡർ എവിടെയെത്തി എന്ന് ഉപഭോക്താക്കൾക്ക് ട്രാക്ക് ചെയ്യാം.
- **ദ്വിഭാഷാ പിന്തുണ (Bilingual)**:
  - മലയാളം & ഇംഗ്ലീഷ് ഭാഷകൾക്കിടയിൽ ഒറ്റ ക്ലിക്കിൽ സ്വിച്ച് ചെയ്യാം.

## 🚀 ആപ്ലിക്കേഷൻ എങ്ങനെ പ്രവർത്തിപ്പിക്കാം? (How to Run)

```bash
cd /Users/nikhilkilivayil/.gemini/antigravity/scratch/shop_platform

# http://localhost:3000
```

## 📁 പ്രോജക്റ്റ് ഫയലുകളുടെ ഘടന (Project Structure)
- `server.js`: ഹൈ-പെർഫോമൻസ് REST API സെർവർ & സ്റ്റാറ്റിക് വെബ് സെർവർ.
- `db.js`: Node.js നേറ്റീവ് SQLite (`node:sqlite`) ഡാറ്റാബേസ് കണക്ഷൻ.
- `seed.js`: പ്രാരംഭ ഉൽപ്പന്നങ്ങളും കാറ്റഗറികളും അഡ്മിൻ അക്കൗണ്ടും തയ്യാറാക്കൽ.
- `public/index.html`: കസ്റ്റമർ സ്റ്റോർഫ്രണ്ടും അഡ്മിൻ പാനലുമുള്ള റെസ്‌പോൺസീവ് സിംഗിൾ പേജ് ആപ്പ്.
- `public/styles.css`: ഗ്ലാസ്മോർഫിസം, ആനിമേഷനുകൾ, പ്രിന്റബിൾ ബിൽ സ്റ്റൈലുകൾ അടങ്ങിയ മോഡേൺ CSS.
- `public/app.js`: കാർട്ട്, ഓൺലൈൻ പേയ്‌മെന്റ്, ഓർഡർ ട്രാക്കിംഗ്, അഡ്മിൻ കൺട്രോളുകൾ.
- `test.js`: സമ്പൂർണ്ണ ഇൻ-പ്രോസസ് ഓട്ടോമേറ്റഡ് ടെസ്റ്റ് സ്യൂട്ട്.
